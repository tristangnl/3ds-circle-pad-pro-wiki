To use Rehid, you need a modded 3DS running a recent version of [Luma3DS](https://github.com/LumaTeam/Luma3DS) CFW.

## Rehid - Luma3ds

<Card title="Rehid" githubUrl="https://github.com/hax0kartik/rehid">

REHID allows you to **remap** Nintendo 3DS **controls** in **any game** by patching it. You can create a different control **layout for each game**. Since the April 5th, 2026 release, **Circle Pad Pro** support has been added, meaning you can make the accessory compatible with any 3DS game that **originally did not support it**.

This patch is a real game changer, forcing the 3DS to read inputs from the Circle Pad Pro and even allowing you to remap **touchscreen areas**.

<small>e.g. For example, you can map the right Circle Pad to L and R (in games where L and R are used to rotate the camera), and remap the L, R, ZL, and ZR triggers to other buttons or touchscreen inputs to create shortcuts.</small>

#### Remarks: 
- Rehid **does not add new gameplay features** not present in the original game, such as a free camera.
- Rehid **does not work** with **DS** and **GBA virtual console** games.
- Some **issues may occur** since the project is still in an **experimental state**.
