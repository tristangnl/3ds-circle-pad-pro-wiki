Patches are programs that run **on top** of a game or the operating system, adding or modifying features **without altering the original software**. The following is a list of Nintendo 3DS patches that affect the Circle Pad Pro and/or C-Stick, adding compatibility or improving controls.

To use these patches, you need a modded 3DS running a recent version of [Luma3DS](https://github.com/LumaTeam/Luma3DS) CFW.

For installation instructions and access to the project repositories, please follow the red GitHub links.

## The Legend Of Zelda: Ocarina Of Time 3D - Free Camera Patch

<Card title="OoT3D Standalone Free Cam CPP" githubUrl="https://github.com/tristangnl/OoT3D_Standalone_Free_Cam_CPP" youtubeId="Ai_3MEJ3sHk">

This patch allows 3DS systems (old and new) and emulators (Citra/Azahar) to control the **camera** in The Legend of Zelda: Ocarina of Time 3D with use of the C-Stick or the Circle Pad Pro, just like Majora's Mask 3D.

It supports the **EUR**, **USA**, and **JPN** versions of the game.

#### **Features:** 
The free camera's settings can be adjusted with the following button combinations:
- L + D-Pad Up/Down = Increase/Decrease Sensitivity
- L + D-Pad Left/Right = Invert Axes (Neither, Just X, Just Y, Both)

#### **Remarks:**

It makes you wonder why Nintendo didn’t add this by default in an update. At least it’s now possible thanks to this game-changing patch, and it works perfectly.

</Card>

## The Legend Of Zelda: Majora's Mask 3D - Project Restoration

<Card title="Project Restoration" githubUrl="https://github.com/leoetlino/project-restoration">

In Zelda: Majora’s Mask 3D, the ZL and ZR triggers of the Circle Pad Pro simply duplicate the L and R buttons, which is unfortunate since they could be used for additional shortcuts.

Originally created to **restore** aspects of the game that were not faithful to the original version of Majora's Mask, this patch also **improves the gameplay** experience by **adding various shortcuts** using ZL and ZR.

It supports the **EUR**, **USA**, and **JPN** versions of the game.

See the project **website** for a full list of features: https://restoration.zora.re/

#### **Remarks:**
With this patch, Zelda: MM3D is finally a 4/4 in relevance. Unfortunately, the shortcuts are not available for users who do not have a Circle Pad Pro or a New 3DS.

</Card>
