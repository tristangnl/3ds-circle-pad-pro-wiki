A homebrew is **unofficial software** made by **independent developers**. It allows users to run **custom apps**  on the console, such as tools, emulators, games, and more.

To install these homebrews, you need a modded 3DS running a recent version of [Luma3DS](https://github.com/LumaTeam/Luma3DS) CFW. Most of them are available on [Universal Updater](https://universal-team.net/projects/universal-updater).

For installation instructions and access to the project repositories, please follow the red GitHub links.

**[New 3DS Only](#cstick-homebrews)**

## Virtual Boy Emulator - Red Viper

<Card title="Red Viper" githubUrl="https://github.com/skyfloogle/red-viper" youtubeId="5fhiCJBJsTU">

Red Viper is a **Virtual Boy emulator** for the Nintendo 3DS that runs games at **full speed** and supports the system’s **stereoscopic 3D** display.

It supports Circle Pad Pro input: 
- **right Circle Pad** is mapped to the Virtual Boy’s **right D-Pad**
- **ZL** is mapped to **A**
- **ZR** is mapped to **B**

#### **Remarks:**

This project is the **first** Nintendo 3DS homebrew project to support the Circle Pad Pro. This achievement was made possible thanks to the amazing work of [Skyfloogle](https://github.com/skyfloogle), who dedicated time to researching and understanding how the accessory works.
</Card>
